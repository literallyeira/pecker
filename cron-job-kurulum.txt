================================================================================
  GITHUB'A HER 10 DAKİKADA TETİK (cron-job.org) — BASİT ADIMLAR
================================================================================

ÖNCE: GitHub'da "Personal Access Token" (PAT) lazım (ücretsiz).

  A) GitHub.com → sağ üst profil → Settings
  B) Sol menü en altta "Developer settings" → "Personal access tokens" → "Tokens (classic)"
  C) "Generate new token (classic)"
  D) Note: örn. cron-forum
  E) Süre: 90 day veya No expiration (sen bilirsin)
  F) İşaret kutuları: "repo" kutusunu işaretle (tam yetki; public repo için yeterli)
  G) Generate → çıkan token'ı BİR YERE KOPYALA (bir daha gösterilmez)

================================================================================
  cron-job.org
================================================================================

  1) https://cron-job.org → Sign up (ücretsiz hesap aç) veya giriş yap

  2) Girişten sonra: "Cronjobs" veya "+" / "Create cronjob" benzeri buton

  3) Title (başlık): istediğin isim, örn: github forum poll

  4) URL (adres) — TAM olarak şu (kopyala-yapıştır):

     https://api.github.com/repos/literallyeira/pckwoods/dispatches

  5) Schedule (zamanlama):
     - "Every 10 minutes" veya "Custom" ile 10 dakikada bir seçeneklerinden birini seç
     (Arayüz İngilizce olabilir; "every X minutes" = her X dakika)

  6) ÖNEMLİ: Sadece URL yetmez — POST ve başlık lazım. Sayfada şunları ara:
     - "Advanced" / "Gelişmiş" / "Show advanced" / "HTTP" sekmesi
     - "Request method" → POST seç (GET değil!)

  7) Headers (Başlıklar) — genelde "Add header" veya tablo:
     Birinci satır:
       Name:  Accept
       Value: application/vnd.github+json

     İkinci satır:
       Name:  Content-Type
       Value: application/json

     Üçüncü satır:
       Name:  Authorization
       Value: Bearer BURAYA_TOKEN_YAPIŞTIR

     (Bearer + boşluk + ghp_...)

  8) Body / Payload / Request body (İstek gövdesi):
     Tür: JSON / raw — içerik tipi mutlaka JSON
     İçerik (tam olarak, tek satır):

       {"event_type":"forum_poll"}

     Content-Type header'ı olmadan GitHub "Problems parsing JSON" döndürebilir.

  9) Kaydet / Save / Create

 10) İlk test — cron-job.org'da "Run now" her hesapta yok; bulamazsan sorun değil.
     Aşağıdaki A veya B yeterli.

================================================================================
  TEST — EN KOLAY (PC'den, PowerShell)  —  "Problems parsing JSON" çözümü
================================================================================

  GitHub gövdeyi JSON sanmazsa 400 verir. Content-Type: application/json şart.
  PowerShell'de en sorunsuz yöntem Invoke-RestMethod:

  $token = "ghp_BURAYA_TOKEN_YAPIŞTIR"
  $uri = "https://api.github.com/repos/literallyeira/pckwoods/dispatches"
  $headers = @{
    Authorization = "Bearer $token"
    Accept = "application/vnd.github+json"
  }
  Invoke-RestMethod -Uri $uri -Method Post -Headers $headers -Body '{"event_type":"forum_poll"}' -ContentType "application/json"

  Başarılıysa genelde çıktı boş veya 204; hata olursa kırmızı metin gelir.

  ---

  curl.exe kullanacaksan (Content-Type şart; gövde tek tırnaklı JSON):

  $t="ghp_..."
  curl.exe -sS -X POST -H "Accept: application/vnd.github+json" -H "Content-Type: application/json" -H "Authorization: Bearer $t" --data-raw '{"event_type":"forum_poll"}' "https://api.github.com/repos/literallyeira/pckwoods/dispatches"

  Sonra GitHub → Actions → "Forum → Discord" → yeni koşuda "repository_dispatch".

================================================================================
  TEST — GitHub üzerinden (cron-job değil, ama script çalışıyor mu görürsün)
================================================================================

  Repo → Actions → sol menü "Forum → Discord" → sağ üst "Run workflow" → Run.
  Bu sefer tetikleyici "workflow_dispatch" olur; yine aynı işi yapar (forum kontrolü).

================================================================================
  ÇALIŞMIYORSA
================================================================================

  - URL'de yazım hatası olmasın (literallyeira/pckwoods küçük harf)
  - Method kesin POST olsun
  - Authorization: Bearer ile başlasın (Bearer yazmayı unutma)
  - Body'de tırnaklar düz İngilizce tırnak: "forum_poll"
  - Token süresi dolmuş olabilir; yeni PAT üret

  NOT
================================================================================

  tetikler. İstersen sadece bunu kullan, GitHub schedule'a güvenmek zorunda değilsin.
